## How It Works

```
User → GitHub Secrets (LLM_SECRETS.PERSONAL_CONTEXT)
          ↓
      Job starts
          ↓
  Environment variable (PERSONAL_CONTEXT)
          ↓
  load-context.js parses JSON
          ↓
  Saves to /logs/personal-context/profile.json
          ↓
  Agent uses context throughout job
          ↓
  Updates recorded in updates.jsonl
```

## JSON Schema

Supports these fields:

- **name** - Preferred name/nickname
- **pronouns** - Preferred pronouns
- **timezone** - IANA timezone identifier
- **language** - Primary language code
- **preferences** - Communication style, detail level, code style, notification hours
- **background** - Role, expertise, interests, learning goals
- **projects** - Active/past projects with status and priority
- **context** - Work environment, goals, constraints
- **notes** - Timestamped observations

See `/job/.pi/skills/personal-context/SCHEMA.md` for complete details.

## Usage Example

```javascript
const { execSync } = require('child_process');

// Load personal context
const contextResult = JSON.parse(
  execSync('node /job/.pi/skills/personal-context/load-context.js').toString()
);

if (contextResult.available) {
  const ctx = contextResult.context;
  
  // Personalize greeting
  console.log(`Hi ${ctx.name}!`);
  
  // Respect preferences
  if (ctx.preferences?.communication_style === 'direct') {
    // Keep it brief
  }
  
  // Suggest tools based on expertise
  if (ctx.background?.expertise?.includes('Python')) {
    // Recommend Python solutions
  }
  
  // Reference projects
  const activeProjects = ctx.projects?.filter(p => p.status === 'active');
}
```
