# 5Levels Website

Bilingual (English/Japanese) educational explanations using the "5 Levels" methodology.

## Features

- **5-Level Explanations**: From child-level simplicity to expert-level depth
- **Bilingual Support**: Full English and Japanese content with cultural adaptation
- **Modern Design**: Clean, responsive interface with the exact color system
- **Search & Filter**: Find topics easily across both languages
- **Source Citations**: Proper attribution for all research

## Design System

### Typography
- **Headings**: Copernicus Trial (serif) with Georgia fallback
- **Body**: Hanken Grotesk (sans-serif)
- **Responsive**: Fluid typography using `clamp()`

### Colors
- **Background**: `#F9F9F9`
- **Text**: `#111111`
- **Level 1**: `#E3B341` (Gold)
- **Level 2**: `#E07A3F` (Orange)
- **Level 3**: `#C06C84` (Rose)
- **Level 4**: `#4C78A8` (Blue)
- **Level 5**: `#2A8F87` (Teal)

### Layout
- **Max width**: 800px centered container
- **Border radius**: 24px for cards
- **Shadows**: Subtle, layered depth
- **Spacing**: Consistent scale using CSS variables

## Adding Topics

### Method 1: Using the Script

```bash
# Create your topic JSON file following the structure
node scripts/add-topic.js path/to/your-topic.json
```

The script will:
1. Validate the topic structure
2. Save to `public/data/topics/`
3. Rebuild the topics index
4. Provide the URL path

### Method 2: Manual

1. Create JSON file in `public/data/topics/[slug].json`
2. Run `node scripts/rebuild-index.js`

## Topic Structure

```json
{
  "id": "unique-slug",
  "keyword": {
    "en": "English Keyword",
    "ja": "日本語キーワード"
  },
  "created": "2026-02-14T16:00:00Z",
  "colors": {
    "level1": "#E3B341",
    "level2": "#E07A3F",
    "level3": "#C06C84",
    "level4": "#4C78A8",
    "level5": "#2A8F87"
  },
  "levels": {
    "en": [
      {
        "level": 1,
        "title": "Child (Age 5-10)",
        "content": "Simple explanation..."
      },
      // ... levels 2-5
    ],
    "ja": [
      {
        "level": 1,
        "title": "子ども（5〜10歳）",
        "content": "シンプルな説明..."
      },
      // ... levels 2-5
    ]
  },
  "sources": [
    {
      "title": "Source Title",
      "url": "https://example.com",
      "language": "en"
    }
  ]
}
```

## Level Guidelines

### Level 1: Child (5-10 years)
- Simple everyday language
- Concrete examples from daily life
- No jargon or technical terms
- 2-3 short paragraphs

### Level 2: Teen (13-17 years)
- More detail and context
- Relatable scenarios
- Basic mechanisms
- 3-4 paragraphs

### Level 3: Undergraduate Student
- Technical terminology
- Academic frameworks
- Historical context
- 4-5 paragraphs

### Level 4: Graduate Student
- Advanced concepts
- Research methodologies
- Critical analysis
- 5-6 paragraphs

### Level 5: Expert
- Cutting-edge research
- Unsolved problems
- Field debates
- Future directions
- 6-8 paragraphs

## Cultural Adaptation

Don't just translate—adapt:
- Use culturally relevant examples
- Different metaphors for each language
- Region-specific applications
- Local cultural context

## Integration with thepopebot

Topics are automatically generated by thepopebot when users send `/5levels [keyword]` in Telegram. The bot:
1. Researches the topic in English and Japanese
2. Generates culturally-adapted 5-level explanations
3. Creates the JSON file
4. Commits to the repository
5. Website rebuilds automatically

See `/job/.pi/skills/academic-research/SKILL.md` for the bot's research instructions.
