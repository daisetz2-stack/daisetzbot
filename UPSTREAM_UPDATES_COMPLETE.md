## How It Works

### New Directory Structure

```
/custom/                    # Your customizations (protected from updates)
  ├── operating_system/    # Your bot config
  └── skills/              # Your custom skills

/operating_system/         # Defaults (updated from upstream)
/.pi/skills/               # Core skills (updated from upstream)
```

### Automatic Resolution

- System checks `/custom/` first
- Falls back to defaults if not found
- Git merge strategies prevent conflicts

## Quick Start

### For Existing Users (Recommended)

```bash
# 1. Migrate your customizations
npm run migrate

# 2. Verify setup
npm run validate

# 3. Add upstream remote
git remote add upstream https://github.com/stephengpope/thepopebot.git

# 4. Get updates anytime
git fetch upstream && git merge upstream/main
```

### For New Users

Your customizations go in `/custom/operating_system/`:

```bash
# Customize personality
cp operating_system/SOUL.md custom/operating_system/SOUL.md
nano custom/operating_system/SOUL.md

# Verify
npm run validate
```
